# Actividad: Archivos(File)
## Descripción
Este programa simula un tablero de juego 5x5 inicializa el mapa con simbolos de agua y posiciona manualmente tres elementos diferentes barco(B) un disparo fallido(o) y un impacto(x), tras mostrar el tablero en la pantalla, el programa nos pide el nombre de usuario y crea un archivo de texto llamado tablero.txt en donde guardo el nombre y la matriz.
## Temas aplicados
- arreglos bidimensionales 
- ciclos anidados de for 
- manipulación de archivos en c
- fgets

## Compilación
gcc main.c -o batalla_file
## Ejecución
./batalla_falla
