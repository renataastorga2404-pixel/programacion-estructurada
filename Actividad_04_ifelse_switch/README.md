# Actividad: if else y switch
## Descripción
### Programa 1:
El programa solicita la edad del usuario y mediante el if else determina si la persona es mayor o menor de edad.
### Programa 2:
Te permite ingresar un n´´umero entero y evalúa matematicamente gracias al modulo si el valor crresponde a un número par o impar
### Programa 3:
Este programa analiza el numero que ingresó el usuario para verificar si es primo o si es un número compuesto.
### Programa 4:
El programa le solicita al usuario el promeduo actual del alumno y la cantidad de materias reprobadas para evaluar mediante operadores lógicos, si es que el estudiante cumple con los requisitos minimos para obtener una beca.
### Programa 5:
El programa cuenta con un menu interactivo en el que decides si quieres analizar un número, usar la calculadora o salir del programa.
Al analizar el numero te señala si el número que escogiste es par o impar, por el otro lado si usas la calculadora tienes las opciones de sumar o restar entre dos numeros, o también esta la opción de regresar al menu. 

## Temas aplicados
- if else
- switch
- do-while
- operadores aritmeticos
- operadores logicos
