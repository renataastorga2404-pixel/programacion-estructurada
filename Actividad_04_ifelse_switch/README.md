# Actividad: if else y switch
## Descripción
### Programa 1:
Al conocer tu edad te cataloga en menor a mayor de edad.
### Programa 2:
Ingresas un numero y el programa evalua el numero señalandote si es impar o par.
### Programa 3:
Ingresas un numero y el programa evalua si es un numero primo o no es primo.
### Programa 4:
Ingresas tu promedio actual y tus materias reprobadas y el programa evalua si obtienes una beca dependiendo de sus requisitos.
### Programa 5:
El programa cuenta con un menu interactivo en el que decides si quieres analizar un número, usar la calculadora o salir del programa.
Al analizar el numero te señala si el número que escogiste es par o impar, por el otro lado si usas la calculadora tienes las opciones de sumar o restar entre dos numeros, o también esta la opción de regresar al menu. 

## Temas aplicados
- if else
- switch
- do-while
- operadores aritmeticos
- operadores logicos
  
## Compilación
gcc edad.c -o edad
gcc par_impar.c -o impar
gcc primos.c -o primos
gcc promedio.c -o promedio
gcc menu.c -o calculadora
## Ejecución
./edad
./primos
./impar
./promedio
./calculadora
