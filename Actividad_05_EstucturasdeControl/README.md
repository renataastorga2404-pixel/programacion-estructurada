# Actividad: Estructuras de Control
## Descripción
### Programa 1: Promediar
Este programa cuenta con un menú interactivo que permite al usuario calcular el promedio de sus calificaciones ademas solicita el número total de materias y, posteriormente, te pide ingresar la calificación de cada una de ellas para después darte el promedio final.
### Programa 2: While
El programa solicita al usuario ingresar números de forma continua a través de un ciclo while así que el programa realiza y nos muestra una suma acumulada en cada iteración por ejemplo: si se ingresa 4, el total es 4; si luego se ingresa 5, el total cambia a 9; si después se ingresa 3, cambia a 12, y así sucesivamente.
### Programa 3:Menu
Este programa solo es para enseñar como funciona un menu con while es algo sencillo y basico, cuenta con dos opciones escenciales continuar dentro del flujo  o salir del programa, es mas que nada para demostrar como funciona.
## Temas aplicados
- for
- while
- operadores aritmeticos 
## Compilación
gcc main.c -o promediar
gcc main.c -o while
gcc main.c -o menu
## Ejecución
./promediar
./while
./menu
