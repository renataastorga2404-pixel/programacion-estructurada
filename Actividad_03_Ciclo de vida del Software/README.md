# Actividad: Ciclo de vida del Software
## Descripción
A diferencia de las otras prácticas esta actividad consiste solo en el concepto del cliclo de vida del software, este concepto define el conjunto de fases que transita in proyecto desde su inicio hast el producto final, su proposito es grarantizar la entrega de este producto que sea eficiente y de alta calidad además de que cumpla estrictamente con los requisitos del usuario.
Planificación y Análisis de Requisitos: Definición del alcance del proyecto y las necesidades del cliente.

## Diseño de Arquitectura:
Modelado de la estructura del sistema, diagramas de flujo y bases de datos antes de programar.

## Desarrollo / Codificación: 
Fase de traducción de los diseños a código fuente real como es el lenguaje C.

## Pruebas:
Aqui detectas y existe la depuración y corrección de errores (bugs) en el software.

## Implementación:
Liberas el programa para el uso del usuario.

## Mantenimiento:
Realizas actualizaciones continuas, mejoras de rendimiento y soporte ante fallas operativas.
