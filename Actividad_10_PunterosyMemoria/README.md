# Actividad: Punteros
## Descripción
Este programa solicita al usuario un número entero en el rango del 1 al 100 y aplica la funcion f_doble para calcular y retornar el dible del número mediante el paso por valor y luego invoca a la función f_triple utilizando el paso por referencia mediante un apuntador int *a, de esta forma accede a la dirección de memoria de la variable para triplicar su valor original.

## Temas aplicados
- Funciones
- paso de parametros+
- apuntadores
- operadores aritmeticos
  
## Compilación
gcc main.c -o prog_multiplicar
## Ejecución
./prog_multiplicar
