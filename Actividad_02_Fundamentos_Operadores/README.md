# Actividad: Operadores Lógicos
## Descripción
El programa analiza el esattus escolar de el estudiante para determinar si cumple con el perdil que se requiere , atravez de la captura de datos, como su promedio y materias, el sistema emplea condiciones logicas para evaluar si el alumno es aprobado o rechazado del el programa de becas 
## Temas aplicados
- if else
- operadores logicos
- if anidado
## Compilación
gcc main.c -o prog_evaluacion
## Ejecución
./prog_evaluacion
